자주 묻는 질문

실제 사용자들이 물어본 것들 — 차단, 첫 실행, 이력 보존, 업데이트, PLC 파일 등.

자주 묻는 질문

실제 사용자 문의에서 나온 질문과 답을 계속 추가합니다.

도면이 정말 외부로 안 나가나요?

네. 프로그램은 회사 PC 안에서만 동작하고, 산출물을 외부로 전송하는 코드가 없습니다. 인터넷 통신은 "새 버전 있나" 버전 숫자 조회 하나뿐이며 이것도 끌 수 있습니다. 요청하시면 보안 검토용 상세 자료를 드립니다.

설계팀이 뭘 바꿔야 하나요?

아무것도요. 지금처럼 공유폴더에 저장만 하면 됩니다. 날짜를 붙여 새 파일로 저장하는 관행(도면_240901.pdf)도, 덮어쓰기도 모두 자동으로 인식합니다.

어떤 파일을 볼 수 있나요?

내용 비교(글자·표·그림 전/후)는 DXF·PDF·XLSX. 그 외 형식(DWG 원본, 한글, PLC 프로그램 등)은 확장자만 등록하면 "언제 무엇이 바뀌었나"와 판 이력을 관리합니다.

CAD 프로그램이 있어야 하나요?

아니요. 비교와 전/후 사진은 프로그램이 자체적으로 만듭니다. 원본을 열 때만 그 PC의 기본 프로그램(CAD 뷰어·엑셀 등)을 사용합니다.

서버나 IT 인프라가 필요한가요?

아니요. 파일서버(공유폴더)에 접근되는 일반 사무용 PC 1대에 설치하면 됩니다. DB 서버·웹 서버·계정 체계 전부 필요 없습니다.

Drev는 무슨 뜻인가요?

Document Revision의 줄임입니다. 도면(Drawing)의 Rev 관리에서 출발했지만, 목표는 프로젝트에서 오가는 모든 문서 — 도면·BOM·사양서·발주서 — 의 개정을 지키는 것입니다. 그래서 지금도 문서 유형에 독립적인 구조로 만들어져 있습니다.

다운로드나 실행이 차단돼요

업무용 PC에서는 대개 그냥 됩니다. 파란 SmartScreen 경고가 뜨면 [추가 정보]→[실행]을 누르시면 됩니다.

개인용으로 새로 설치한 Windows 11에는 '스마트 앱 컨트롤'이 켜져 있어 서명 없는 프로그램의 실행 자체를 막습니다. 기본 다운로드(포터블판)는 Microsoft가 서명한 정식 Python 실행기로 동작하도록 만들어 이 경우에도 그대로 실행됩니다 — 막히면 포터블판을 쓰세요.

첫 실행이 오래 걸려요 / 안 열리는 것 같아요

첫 실행은 Windows 보안 검사 때문에 1~3분 걸릴 수 있습니다 — 한 번만 클릭하고 기다려주세요. 이후엔 몇 초면 뜹니다. 이미 실행 중일 때 또 더블클릭하면 기존 화면이 창으로 다시 열립니다.

업데이트는 어떻게 하나요? 기존 이력은요?

프로그램 안에서 버튼 하나입니다. 새 버전이 나오면 화면 위에 알림이 뜨고, [지금 업데이트]를 누르면 프로그램이 스스로 내려받아 교체하고 다시 시작합니다 — 압축을 풀거나 폴더를 옮기실 일이 없습니다.

이력·설정은 프로그램과 분리된 파일(state.db, config.yaml)에 저장되어 업데이트·제거가 건드리지 않습니다. DB 구조가 바뀌는 업데이트도 자동 마이그레이션되며, 주 1회 자동 백업까지 됩니다. 교체가 실패하면 이전 판 그대로 되돌아갑니다.

첫 검사가 몇 시간씩 걸려요

정상입니다 — 첫 검사(기준선)는 서버의 모든 파일을 한 번 읽습니다. 수만 개면 몇 시간까지 걸릴 수 있고 진행률이 화면에 표시됩니다. 다음 검사부터는 바뀐 파일만 봐서 보통 몇 분 안에 끝납니다.

PLC 프로그램 파일도 감시되나요?

네 — [설정]의 감시 확장자에 .gxw, .xgwx 같은 확장자를 추가하면 "언제 누가 바꿨나"(파일 수준)와 판 이력·확인·바로 열기가 됩니다. 래더 내용 비교는 제조사 독점 포맷이라 지원 예정 항목입니다.

프로그램을 껐다 켜도 되나요? 폴더 삭제가 안 돼요

언제든 창을 닫아도 안전합니다 — 검사 중이어도 진행분은 저장되어 다음 검사가 이어받습니다. 폴더가 안 지워지면 프로그램이 아직 실행 중인 것이니 작업 관리자에서 Drev를 종료한 뒤 지우세요.

여러 명이 같이 볼 수 있나요?

화면은 설치된 PC에서 열리고, 팀 공유는 아침 브리핑 메일로 합니다 — 담당자별로 프로젝트 브리핑을 받고 메일 속 링크로 '확인함'을 남기는 구조입니다. 다중 접속 웹 대시보드는 정식판 로드맵에 있습니다.

정말 무료인가요?

베타 기간에는 전 기능 무료입니다. 정식 버전은 유료화 예정이지만, 베타 참여자에게는 별도 혜택을 드릴 계획입니다.

지금 바로 무료로 써보세요

설치 5분 · 가입 없음 · 도면은 회사 밖으로 나가지 않습니다
