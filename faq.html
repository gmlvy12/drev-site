자주 묻는 질문

써 보신 분들이 묻는 것부터 답을 추가합니다.

도면이 정말 외부로 안 나가나요?

네. 프로그램은 회사 PC 안에서만 동작하고, 산출물을 외부로 전송하는 코드가 없습니다. 스스로 하는 인터넷 통신은 "새 버전 있나" 버전 숫자 조회와(이것도 끌 수 있습니다), 새 판이 있을 때 새 판 파일을 받는 것(사람이 [설치]를 눌렀을 때, 그리고 기본 설정에서는 예약 검사가 끝난 뒤 자동으로 — 작은 판은 drev.co.kr, 큰 판은 GitHub)과, '의견 보내기'를 직접 눌렀을 때 적은 내용·버전·진단 줄을 보내는 것뿐입니다 (둘 다 끌 수 있습니다). 요청하시면 보안 검토용 상세 자료(통신 목록·설치 위치·삭제 시 남는 것)를 드립니다.

화면은 그 PC(127.0.0.1)에서만 열립니다. 메일의 [감시 PC에서 확인] 링크도 그 PC에서 누를 때만 동작하며, 수신자는 회신으로 확인하고 기록은 담당자가 그 PC의 화면에서 남기는 운영을 권장합니다.

설계팀이 뭘 바꿔야 하나요?

아무것도요. 지금처럼 공유폴더에 저장만 하면 됩니다. 날짜를 붙여 새 파일로 저장하는 관행(도면_240901.pdf)도, 덮어쓰기도 모두 자동으로 인식합니다.

어떤 파일을 볼 수 있나요?

글자·표 비교는 DXF·PDF·XLSX·DOCX·HWPX, 그림 전/후 비교는 도면(DXF·PDF·DWG)만입니다 — 엑셀·워드·한글 안의 그림·개체는 비교하지 않고, 그 사실을 변경 행에 적습니다. DWG 원본은 이 PC에 ODA File Converter(회사 사용은 ODA 회원 필요)가 있으면 같은 수준으로 비교하고(오토캐드 연동은 베타 — [설정]의 [DWG 변환 시험]으로 먼저 확인하세요), 없으면 파일 안의 미리보기 그림과 변경 사실만 봅니다. 스캔본이나 CAD에서 SHX 글꼴로 출력해 글자가 그림이 된 PDF는 Windows 내장 OCR(한국어 언어팩이 있는 PC)로 표제란·글자를 읽어 비교하되 'OCR 추정값'으로 표시합니다. 그 외 형식은 — 한글 hwp·doc 등은 기본으로, PLC 프로그램 등은 확장자를 등록하면 — "언제 무엇이 바뀌었나"와 판 이력을 관리합니다.

CAD 프로그램이 있어야 하나요?

아니요. 비교와 전/후 사진은 프로그램이 자체적으로 만듭니다. 원본을 열 때만 그 PC의 기본 프로그램(CAD 뷰어·엑셀 등)을 사용합니다. 예외는 DWG 원본 — 글자·그림 비교까지 하려면 ODA File Converter(회사 사용은 ODA 회원 필요; CADian·ZWCAD 등 어느 CAD로 만든 DWG든 됨)가 그 PC에 있어야 합니다(오토캐드 연동은 베타). [설정]에서 자동으로 찾습니다.

서버나 IT 인프라가 필요한가요?

아니요. 파일서버(공유폴더)에 접근되는 일반 사무용 PC 1대에 설치하면 됩니다. DB 서버·웹 서버·계정 체계 전부 필요 없습니다.

Drev는 무슨 뜻인가요?

Document Revision의 줄임입니다. 도면(Drawing)의 Rev 관리에서 출발했지만, 목표는 프로젝트에서 오가는 모든 문서 — 도면·BOM·사양서·발주서 — 의 개정을 지키는 것입니다. 그래서 지금도 문서 유형에 독립적인 구조로 만들어져 있습니다.

다운로드나 실행이 차단돼요

업무용 PC에서는 대개 그냥 됩니다. 파란 SmartScreen 경고가 뜨면 [추가 정보]→[실행]을 누르시면 됩니다.

개인용으로 새로 설치한 Windows 11에는 '스마트 앱 컨트롤'이 켜져 있어 서명 없는 프로그램의 실행 자체를 막습니다. 포터블판은 Python Software Foundation이 서명한 정식 Python 실행기로 동작하도록 만들어 이 경우에도 그대로 실행됩니다 — 막히면 포터블판을 쓰세요.

첫 실행이 오래 걸려요 / 안 열리는 것 같아요

첫 실행은 Windows 보안 검사 때문에 1~3분 걸릴 수 있습니다 — 한 번만 클릭하고 기다려주세요. 이후엔 몇 초면 뜹니다. 이미 실행 중일 때 또 더블클릭하면 기존 화면이 다시 열립니다(창 구성요소가 없는 PC에서는 브라우저 탭으로).

업데이트는 어떻게 하나요? 기존 이력은요?

프로그램 안에서 버튼 하나입니다. 새 버전이 나오면 화면 위에 알림이 뜨고, 왼쪽 메뉴 맨 위의 [새 버전 설치]를 누르면 프로그램이 스스로 내려받아 교체하고 다시 시작합니다 — 압축을 풀거나 폴더를 옮기실 일이 없습니다.

이력·설정은 프로그램과 분리된 파일(state.db, config.yaml)에 저장되어 업데이트·제거가 건드리지 않습니다. DB 구조가 바뀌는 업데이트도 자동 마이그레이션되며, 주 1회 자동 백업까지 됩니다. 교체가 실패하면 이전 판 그대로 되돌아갑니다(교체하는 몇 초 사이에 PC 전원이 꺼진 경우는 예외 — 그때는 다운로드 페이지의 포터블판을 같은 폴더에 다시 풀면 이력·설정은 그대로입니다).

첫 검사가 몇 시간씩 걸려요

정상입니다 — 첫 검사(기준선)는 서버의 모든 파일을 한 번 읽습니다. 수만 개면 몇 시간까지 걸릴 수 있고 진행 상황이 화면에 표시됩니다. 다음 검사부터는 바뀐 파일만 봐서 보통 몇 분 안에 끝납니다.

PLC 프로그램 파일도 감시되나요?

네 — [설정]의 감시 확장자에 .gxw, .xgwx 같은 확장자를 추가하면 "언제 무엇이 바뀌었나"(파일 수준)와 판 이력·확인·바로 열기가 됩니다. 래더 내용 비교는 제조사 독점 포맷이라 지원 예정 항목입니다.

프로그램을 껐다 켜도 되나요? 폴더 삭제가 안 돼요

언제든 창을 닫아도 안전합니다(브라우저 탭으로 열린 경우에는 탭을 닫아도 프로그램이 계속 돕니다 — 완전히 끄려면 설정 › 프로그램 종료) — 검사 중이면 안전하게 멈추고 그 검사는 되돌리며(변경은 유실되지 않고 다음 검사가 다시 감지), 읽어 둔 내용은 남아 다음 검사가 빨라집니다. 폴더가 안 지워지면 프로그램이 아직 실행 중인 것이니 작업 관리자에서 Drev를 종료한 뒤 지우세요.

여러 명이 같이 볼 수 있나요?

화면은 설치된 PC에서 열리고, 팀 공유는 아침 브리핑 메일로 합니다 — 담당자별로 프로젝트 브리핑을 받고, 확인 기록은 감시 PC의 화면에서 남깁니다 (메일 수신자는 회신으로 알리고 담당자가 기록하는 운영). 다중 접속 웹 대시보드는 정식판 로드맵에 있습니다.

지우면 무엇이 남나요? 여러 PC에 설치해도 되나요?

[앱 및 기능]에서 제거하면 프로그램과 자동 실행 작업(작업 스케줄러 'ProjectWatcher')이 지워지고, %LOCALAPPDATA%\Drev의 config.yaml(메일 설정 포함 — SMTP 비밀번호는 이 PC 계정으로 암호화)·state.db(이력)·briefs·backups· watcher.log는 남습니다. 완전히 지우려면 그 폴더를 삭제하세요. 여러 PC에 설치해도 되지만 이력은 PC마다 따로 쌓이므로 감시 PC 1대를 권장합니다.

인터넷이 안 되는(폐쇄망) PC에서도 되나요?

네. 검사·비교·브리핑은 인터넷이 필요 없습니다. 새 버전 확인만 실패하고 조용히 건너뜁니다. 업데이트는 다른 PC에서 받은 설치 파일을 덮어쓰면 됩니다(설정·이력은 유지).

정말 무료인가요?

베타 기간에는 전 기능 무료입니다. 베타 기간 중 설치한 판은 기간이 끝나도 계속 동작하며, 이력(state.db)은 언제나 여러분의 파일입니다. 정식판은 유료 예정이고 베타 사용자에게는 별도 조건을 안내드립니다. 사내 PC 대수 제한은 없습니다(감시 PC 1대 권장).
