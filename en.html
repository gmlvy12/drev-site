100% change detection

File fingerprints (hashes) catch every change, and date-suffixed saves (drawing_240901 → _241001) are automatically recognized as new revisions of the same drawing and compared.

📷

Before/after evidence

Changed spots on drawings are cropped with red boxes as before/after images; BOMs get row-level color diffs plus a purchasing-impact summary (added / removed / quantity delta).

⚠️

Mistake signals

Content changed but Rev untouched, drawing–BOM quantity mismatch, spec conflicts between drawings — suspicious signs are flagged with evidence before they become accidents.

Worried about security? That's exactly how we built it

We know a leaked drawing is game over — we come from manufacturing too.

✓
Fully on-premise Drawings, BOMs and documents are never transmitted anywhere. No cloud upload, no external server. Even the UI opens only on that PC (127.0.0.1).
✓
Read-only by construction There is no code that modifies, moves or deletes watched files — an automated test scans the entire source and fails the build if a write command ever appears.
✓
Your data stays on your PC All history lives in a single file (state.db) in the install folder, with automatic weekly backups. Copying the folder is your backup and migration.
✓
The only network call is a version check It fetches one tiny version file to see if an update exists (can be turned off) — and sends nothing else, ever.

Frequently asked questions

Real questions from real users, added as they come.

Do my drawings really never leave the company?

Correct. The program runs entirely inside your PC and contains no code that transmits your files anywhere. The only network call is a version-number check, which you can disable. Security review material is available on request.

What does my design team have to change?

Nothing. Keep saving to shared folders as always. Date-suffixed saves and overwrites are both recognized automatically.

Which file types are supported?

Content comparison (text, tables, visual before/after): DXF, PDF, XLSX. Any other extension (native DWG, HWP, PLC programs, …) can be registered for file-level tracking — who changed what, when — plus revision history.

Do I need CAD installed?

No. Comparisons and before/after images are produced by Drev itself. Your default viewer is only used when you click "Open file".

Do I need a server or IT infrastructure?

No. One ordinary office PC that can reach the shared folder is enough. No database server, no web server, no user accounts.

The download or launch gets blocked

On work PCs it usually just runs — if the blue SmartScreen warning appears, choose [More info]→[Run anyway].

A freshly installed Windows 11 has Smart App Control on, which blocks unsigned programs outright. The main download runs on Microsoft-signed official Python, so it launches even there. If you see the blue SmartScreen banner, click [More info] → [Run anyway].

The first launch feels slow / nothing happens

The first launch can take 1–3 minutes while Windows security scans the files — click once and wait. Afterwards it opens in seconds, and re-launching brings the existing window to the front.

How do updates work? Will they erase my history?

One button, inside the app. When a new version ships you get a notice on screen; press [Update now] and Drev downloads it, replaces itself and restarts — no unzipping, no moving folders.

History and settings live in separate files (state.db, config.yaml) that updates and uninstalls never touch, with automatic schema migration and weekly backups. If a replacement fails, it rolls back to the previous version.

The first scan takes hours

That's normal — the baseline reads every file once. Tens of thousands of files can take a few hours, with progress shown. Daily scans afterwards finish in minutes because unchanged files are skipped.

Can it watch PLC program files?

Yes — add extensions like .gxw or .xgwx in Settings for file-level tracking and revision history. Ladder-level content diffs are on the roadmap (vendor-proprietary formats).

Can several people use it?

The screen opens on the PC it's installed on; the team shares through the morning briefing emails, where each owner acknowledges via a link. A multi-user web dashboard is on the official-release roadmap.

What does "Drev" mean?

Short for Document Revision. It started with drawing (Drawing + Rev) revisions, but the goal is guarding revisions of every project document — drawings, BOMs, specs and purchase orders — which is why the engine is document-type agnostic.

Is it really free?

Everything is free during the beta. The official release will be paid, with special terms planned for beta participants.
