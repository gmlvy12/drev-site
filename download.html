다운로드

무료 베타 다운로드. 설치판·포터블판, Windows 10/11.

지금 바로 받아서 써보세요

베타 기간에는 모든 기능이 무료입니다 — 가입도, 신청도 없습니다.

지금까지 0회 다운로드되었습니다

설치판 권장

설치 마법사로 한 번에. 회사 PC에서 가장 무난합니다.

  • 시작 메뉴·바탕화면 아이콘
  • 윈도우 [앱 및 기능]에서 제거
  • 관리자 권한 불필요
⬇ 설치판 내려받기 · v0.42.0 · 약 36MB

압축을 풀고 Drev-Setup.exe 실행 → 설치 마법사 → 끝.
파란 SmartScreen 경고가 뜨면 [추가 정보] → [실행] (서명 인증서는 정식판에서 적용 예정).
브라우저가 exe를 막지 않는다면 exe로 바로 받기도 됩니다.

포터블판

설치 없이 폴더째. 보안이 엄격한 PC에서도 그대로 실행됩니다.

  • 스마트 앱 컨트롤 PC에서도 실행
  • 압축 풀고 Drev.exe 더블클릭
  • 폴더를 지우면 그것이 곧 제거
⬇ 포터블판 내려받기 · 약 52MB

Microsoft가 서명한 정식 Python 런타임으로 동작합니다. 첫 실행은 보안 검사로 1~3분 걸릴 수 있습니다.
프로그램 안 [설정] → [이 PC에 설치]를 누르면 포터블도 시작 메뉴·바탕화면 아이콘이 생깁니다.

Windows 10/11 64bit · WebView2 런타임(Windows 11·Edge 설치 PC는 기본 포함) · 파일서버(공유폴더) 접근 가능한 PC 1대 · 업데이트는 프로그램 안에서 버튼 한 번(약 0.1MB)
