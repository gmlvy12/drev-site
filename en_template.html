No PDM system? Never miss a change anyway

Built for design teams that live in shared folders — no behavior change required.

🔍

100% change detection (watched formats)

File fingerprints (hashes) catch every change (copies that keep both size and timestamp are caught by the weekly full check), and date-suffixed saves (drawing_240901 → _241001) are automatically recognized as new revisions of the same drawing and compared.

📷

Photos and evidence

Changed spots on drawings are cropped with red boxes (before/after images when the graphics change; old → new value plus the new revision's image when text or values change); BOMs get row-level color diffs with only the changed words highlighted, plus a purchasing-impact summary (added / removed / changed values). Renamed or added columns, moved rows, added sheets, and PDFs whose page numbers shifted are matched correctly too (drawings: PDF and DXF; DWG when a converter is installed).

⚠️

Mistake signals

Content changed but Rev untouched, drawing–BOM spec mismatch, spec conflicts between drawings — suspicious signs are flagged with evidence before they become accidents.

📧

Per-project morning briefing

Every morning at the time you set (7 AM by default — waking the PC from sleep, or, if the time was missed, at the next login (or when the Drev window is opened)), each project gets a briefing as an email draft (sent automatically if an SMTP server is set): "N changes + M to review." A second scan on the same day updates that day's single briefing. The owner acknowledges with one click on the watch PC's screen; email recipients reply, and the owner records it.

🔎

Tag & full-text search

"Where is M-101 used?" — search any equipment tag or text across all drawings and BOMs, then open the file right from the results.

📊

History & reporting

Who acknowledged what and when is kept in your own state.db (before/after images of older revisions for 90 days by default, adjustable in Settings), and the full history exports to Excel for weekly reports and approvals.

Worried about security? That's exactly how we built it

We know a leaked drawing is game over — we come from manufacturing too.

✓
Fully on-premise Drawing, BOM and document files are never transmitted anywhere. No cloud upload, no external server. Even the UI opens only on that PC (127.0.0.1).
✓
Emails carry only what changed — your company picks the mail server If you set up your company mail server (SMTP), briefing emails carry the changed text and cropped before/after images (never the original files) to the recipients you choose — without it, Drev only writes email drafts (.eml). If you enter a public mail service (Gmail, Outlook.com, Naver…), those images pass through that provider's servers, so use your in-house mail server where drawings must stay inside (the settings screen warns you too).
✓
Read-only by construction There is no code that modifies, moves or deletes watched files — if a write, delete or move command ever appears in a module that opens watched files, an automated test stops the release, and a live run checks that the watched folder's fingerprints and timestamps are unchanged after a scan.
✓
Your data stays on your PC All history lives in a single file (state.db) in the app's data folder (%LOCALAPPDATA%\Drev for the installer, the program folder for portable), with automatic weekly backups. Copying the folder is your backup and migration. The mail server password is stored encrypted with your Windows account (DPAPI). This file holds the text of watched documents and page images used for comparison, so treat it like the drawings themselves — disk encryption (BitLocker) on the watch PC is recommended.
✓
On its own, it only checks for a new version and downloads it It fetches one tiny version file to see if an update exists (can be turned off); when a new version is out it downloads the program files after the scheduled scan and replaces itself (can be turned off). Downloaded files are used only when they match the SHA-256 fingerprint in the release list, and the version check carries the installed version number — it sends nothing else on its own. The in-app feedback form, only when you choose to use it, sends what you typed plus the version and a few diagnostic log lines (start/update/error; optional, off by default) — never scan results. Paths, file names, project and drawing numbers, Rev values and error messages containing Korean text are masked; plain system errors (e.g. "database is locked") are kept for diagnosis.

Frequently asked questions

Answers are added as questions come in from people trying it.

Do my drawings really never leave the company?

Correct. The program runs entirely inside your PC and contains no code that transmits your files anywhere. On its own it makes only two kinds of network call — a version-number check (can be disabled), and — by default — after the scheduled scan it downloads a new build when one exists (auto_update: false to disable; small app updates come from drev.co.kr, full runtime updates from GitHub). Sending feedback happens only when you click the button. Security review material (connection list, install location, what remains after uninstall) is available on request.

What does my design team have to change?

Nothing. Keep saving to shared folders as always. Date-suffixed saves and overwrites are both recognized automatically.

Which file types are supported?

Text and table comparison: DXF, PDF, XLSX/XLSM, DOCX, HWPX. Visual before/after comparison: drawings only (DXF, PDF, DWG) — pictures and objects inside Excel, Word and HWPX files are not compared, and each change row says so. Native DWG gets the same comparison when ODA File Converter (company use requires ODA membership) is installed on that PC (AutoCAD support is beta — try [Test DWG conversion] in Settings first); otherwise Drev compares the embedded preview image and reports the change itself. Scanned PDFs and CAD prints whose SHX text became line art are read with the built-in Windows OCR (Korean language pack) so title blocks and text still get compared, flagged as "OCR estimate". Other formats get file-level tracking — HWP, DOC and similar out of the box, PLC programs and others once you register the extension — who changed what, when — plus revision history.

Do I need CAD installed?

No. Comparisons and before/after images are produced by Drev itself. Your default viewer is only used when you click "Open file". The one exception is native DWG: full text and picture comparison needs ODA File Converter (company use requires ODA membership) (works for DWG from any CAD, e.g. CADian, ZWCAD) on that PC (AutoCAD support is beta) — Settings detects it automatically.

Do I need a server or IT infrastructure?

No. One ordinary office PC that can reach the shared folder is enough. No database server, no web server, no user accounts.

The download or launch gets blocked

On work PCs it usually just runs — if the blue SmartScreen warning appears, choose [More info]→[Run anyway].

A freshly installed Windows 11 has Smart App Control on, which blocks unsigned programs outright. The installer is not code-signed, so it can be blocked there. The portable build runs on official Python signed by the Python Software Foundation and launches even under Smart App Control — if the installer is blocked, use the portable build.

The first launch feels slow / nothing happens

The first launch can take 1–3 minutes while Windows security scans the files — click once and wait. Afterwards it opens in seconds, and re-launching brings the existing window to the front.

How do updates work? Will they erase my history?

One button, inside the app. When a new version ships you get a notice on screen; press [Install new version] at the top of the left menu and Drev downloads it, replaces itself and restarts — no unzipping, no moving folders.

History and settings live in separate files (state.db, config.yaml) that updates and uninstalls never touch, with automatic schema migration and weekly backups. If a replacement fails, it rolls back to the previous version (except if the PC loses power during the few seconds of the swap — then unzip the portable package over the same folder again; history and settings are kept).

The first scan takes hours

That's normal — the baseline reads every file once. Tens of thousands of files can take a few hours, with progress shown. Daily scans afterwards finish in minutes because unchanged files are skipped.

Can it watch PLC program files?

Yes — add extensions like .gxw or .xgwx in Settings for file-level tracking and revision history. Ladder-level content diffs are on the roadmap (vendor-proprietary formats).

Can several people use it?

The screen opens on the PC it's installed on; the team shares through the morning briefing emails. The owner acknowledges on the watch PC's screen and email recipients reply to let them know. A multi-user web dashboard is on the official-release roadmap.

What does "Drev" mean?

Short for Document Revision. It started with drawing (Drawing + Rev) revisions, but the goal is guarding revisions of every project document — drawings, BOMs, specs and purchase orders — which is why the engine is document-type agnostic.

Can I close it and start it again? The folder won't delete

Closing the window is always safe (if it opened as a browser tab, closing the tab keeps the program running — use Settings › Quit to stop it). A scan in progress stops cleanly and is rolled back; nothing is lost, the next scan picks it up, and what was already read stays cached so the next scan is faster. If the folder won't delete, the program is still running — end Drev in Task Manager first.

What is left after uninstalling? Can I install on several PCs?

Removing it from Apps & features deletes the program and the scheduled task ('ProjectWatcher'). %LOCALAPPDATA%\Drev keeps config.yaml (mail settings — the SMTP password is encrypted with this PC's Windows account), state.db (history — it contains the text and comparison images of the documents it watched, so treat it like the drawings themselves), briefs, backups and watcher.log. Delete that folder to remove everything. You may install on several PCs, but history is kept per PC, so one watching PC is recommended.

Does it work on an air-gapped (offline) PC?

Yes. Scanning, comparing and briefing need no internet. Only the version check fails and is skipped quietly (you can turn it off in Settings). To update, copy the installer downloaded on another PC over the old one — settings and history are kept. If github.com is blocked at your company, contact us for another download route.

Is it really free?

Everything is free during the beta, and a beta build keeps working after the beta ends — your history (state.db) is always your own file. The official release will be paid, with special terms planned for beta participants. Internet traffic the program makes on its own: one GET of a version file (drev.co.kr/version.json, can be disabled), an update download when you click Install or, by default, after the scheduled scan when a new version exists (auto_update: false to disable), and your own SMTP server only if you enable mail.
